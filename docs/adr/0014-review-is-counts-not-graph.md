# Review is counts and the next Plan item, not the full Graph

A Review for a Direction states how many Points are Clear, how many are not, how many Misses there are, and what the next Point on the Plan is. The full before-after Graph is not part of Review. We rejected a prose-only comment with no numbers.

Superseded: the View shows both the counts and the Graph.
