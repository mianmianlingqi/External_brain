# First release has a read-only View page; the Graph uses three Point states

The Owner has a web View. One address lists Directions; the Owner picks one. It shows Review counts and the Graph. Each Point is Clear, Open, or Blocked. Blocked means a before-Point is not Clear. The View is look-only: no accepting Proposals, no editing the Plan, no Drills. Init gives a link and secret; others cannot open the View. Drills still go through an Agent. This supersedes “no human client” (ADR-0001) and “Review has no Graph” (ADR-0014).
