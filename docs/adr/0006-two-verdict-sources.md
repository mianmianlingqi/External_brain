# A Drill can end in a Brain Verdict or an Owner Verdict

v1 judges more than stored-answer Questions. A Question has an expected answer and the Brain issues the Verdict. A Task has no expected answer (lab, oral, portfolio) and the Owner reports the Verdict. We rejected “any activity with no right or wrong” as a Drill; reading and notes are not Drills. Two sources keep the Verdict a single on/off fact instead of inventing a second progress model.
