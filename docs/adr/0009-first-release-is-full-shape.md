# The first release is the full learning shape

The first release is not a drill-only slice. It stores Points, hangs each Question under one Point, keeps a Graph of Points, writes a Plan as an ordered list of Points, and can give a Review from Verdicts and the Graph. It also includes Tasks the Owner judges, Miss retries, and import from pasted notes. Init still records how an Agent connects. This reverses “do not store Point yet” (ADR-0008).
