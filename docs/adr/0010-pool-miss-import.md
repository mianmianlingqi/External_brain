# The course question pool is not a named bank; first release retries Misses and imports from pasted text

All Questions under a Direction are the pool. We will not add named banks or a public store. A Drill can come from the Plan, from “any Question in this Direction”, or from a Question the Owner names. A Miss is a Question whose latest Verdict is wrong; the Owner can retry Misses as a group. The Owner may paste notes or a lecture to an Agent; the Agent proposes Points and Questions, then stores them in the Brain after we settle whether the Owner must confirm first.
