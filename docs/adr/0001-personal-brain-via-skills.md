# Personal Brain, reached by Agents through Skills

The Brain is a hosted personal service for one Owner, not a shared classroom product. Other Agents interact with it through Skills, so any agent harness can use the same Brain without a custom integration. The Owner has no first-class human client: they use the Brain only through Agents and Skills.

Superseded: the first release includes a read-only View page. Answering still goes through Agents.
