# Seed is a Git template; Fork plus Init expands workspace and Brain

The published project is a Seed Git template, not a running Brain: Skills, contracts, empty shape, no Direction. An Owner forks it and uses an Init Skill to expand onto a Target (local or server). Init produces both a workspace and a running Brain, confirms the first Direction, and records how an Agent connects to the Brain (address and secret). Later Directions are added by a Skill, not by running Init again.
