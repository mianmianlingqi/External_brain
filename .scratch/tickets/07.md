## What to build

The Brain writes a Plan only when asked. The Plan is an ordered list of Points from Verdicts and the Graph, skipping Clear Points. The Owner can edit it. A rewrite keeps Owner edits where it still can. A Drill can pick a Question from the next Plan Point.

## Acceptance criteria

- [ ] A Drill does not rewrite the Plan
- [ ] Update Plan produces an order that respects Links and skips Clear Points
- [ ] Owner edits persist across a later update where still valid
- [ ] A Plan-picked Drill uses a Question under the next Plan Point
- [ ] Tests go only through the Brain interface
