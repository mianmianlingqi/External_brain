## What to build

A Brain can be created with a first Direction. A Review for that Direction is Clear 0, not-Clear 0, Misses 0, and no next Plan Point. A Seed or Fork that has not been through Init-equivalent setup is not a Brain and refuses Brain commands.

## Acceptance criteria

- [ ] Creating a Brain with one named Direction succeeds
- [ ] Review for that Direction reports zero Clear, zero not-Clear, zero Misses, and no next Plan Point
- [ ] Commands that need a Brain fail before Init-equivalent setup
- [ ] Tests go only through the Brain interface (in-memory adapter)

## Blocked by

None (can start immediately)
