## What to build

The Owner can add a before-after Link between two Points. A Link that would loop is rejected. Graph query returns Clear, Open, and Blocked. A Drill can draw a Question from the Direction pool.

## Acceptance criteria

- [ ] A Link means only “learn this Point before that Point”
- [ ] Accepting or adding a Link that would cycle fails; nothing is stored
- [ ] Blocked means a before-Point is not Clear; Open means has items, not Clear, not Blocked
- [ ] A Question can be drawn from all Questions under a Direction
- [ ] Tests go only through the Brain interface
