## What to build

Init expands a Fork onto a Target (Owner machine or server): workspace plus a running Brain, first Direction, Agent connection address and secret, View link and secret. Before Init, the Fork is not a Brain.

## Acceptance criteria

- [ ] Init asks for first Direction, Target, and records both secrets
- [ ] After Init, Brain commands work; before Init they fail
- [ ] Local and server Targets both yield workspace + running Brain
- [ ] Later Directions are not added by running Init again
- [ ] Tests go only through the Brain interface (Init as a caller of that interface)
