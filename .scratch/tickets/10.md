## What to build

The Seed ships Skills that tell any Agent how to perform every Brain command and query used in the first release. A second harness can follow the same Skills against the same Brain.

## Acceptance criteria

- [ ] Skills cover Direction, Point, Question, Task, Proposal, Link, Drill, Miss, Plan, Review, Graph, and Init/View secrets
- [ ] Skills do not invent a second API besides the Brain interface
- [ ] A reader can perform the first-release flows without undocumented commands
- [ ] No requirement to test Skill markdown as a second seam; behaviour stays proven on the Brain interface
