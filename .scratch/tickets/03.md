## What to build

The Owner can add a Point under one Direction and a Question under one Point (expected answer required). A Drill can name a Question or take one from the Direction pool. The Brain issues the Verdict. A Miss is latest-wrong. An empty Point is not Clear. Review counts change after Drills.

## Acceptance criteria

- [ ] A Question without an expected answer is refused
- [ ] Submitting an answer yields right or wrong from the stored expected answer (Agent does not supply the Verdict)
- [ ] Latest-wrong Questions appear as Misses; latest-right removes them
- [ ] An empty Point is not Clear; a Point with all Questions tried and latest-right is Clear
- [ ] Review Clear / not-Clear / Miss counts match that state
- [ ] Tests go only through the Brain interface
