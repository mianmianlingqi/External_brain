## What to build

The Owner can add a Task under exactly one Point and report a Verdict. Misses include latest-wrong Tasks. A Point is Clear only when every Question and Task under it has been tried and is latest-right.

## Acceptance criteria

- [ ] A Task belongs to one Point; it has no expected answer
- [ ] The Owner-reported Verdict is stored; the Brain does not invent a Task Verdict
- [ ] Latest-wrong Tasks appear in Misses for that Direction
- [ ] A Point with a remaining wrong or untried Task is not Clear
- [ ] Tests go only through the Brain interface
